# SKILL Maestro dial panel

Format from the user's CROSS_POLLINATION_SETTINGS panels (SLOPOG): one dial per row, the header count is normative
(the loader halts if the rows do not number EXPECTED_DIALS), and LOCKED dials are the integrity spine: the loader
refuses a LOCKED dial whose value differs from the value maestro.py was tested with. Every score writes this
panel's sha256 into its ledger row, so a sheet can always be traced to the settings that made it. Change an
unlocked dial here, run `maestro.py eval`, and keep the change only if the held-out numbers do not fall.
